# Project conventions

## English only

Everything that belongs to this project is written in English. Never add Chinese
text anywhere, including:

- source code, comments, identifiers and test fixtures
- UI copy, error messages, README and other documentation
- commit messages, branch names, pull request titles and descriptions
- GitHub release notes and release workflow text
- design notes and SVG titles

Release notes are generated from commit messages and pull requests, so commit
messages must be in English too. The people using this app read English; Chinese
release notes are unreadable to them.

If the user writes to you in Chinese, reply in Chinese, but keep every file,
commit and release artifact in English.
